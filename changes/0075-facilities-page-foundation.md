# 0075：设施页面首批基础

状态：已完成（第 8 步的一部分）。

## 目标与依据

开始[虚拟设施](../docs/design/facilities.md)的第 8 步，让玩家在页面看见并操作地块、设施和内容。美术参考用户提供的方块居民、玻璃罩游戏厅与霓虹设施图片。

## 范围

- 协议 24 传出地块价格、产权及份额、设施种类、每份展示内容的剩余时间、进行中的工作；所选居民的内容数量按 `view_as` 返回。
- 手动原语接入买地、建设四种设施、制作广告或游戏、放入内容。服务端继续负责校验和计费。
- Phaser 2.5D 地图显示地块、程序化设施模型和小幅摆臂的方块居民；侧栏支持选地块和上述操作。
- 节点订阅、份额交易、合买、传送、访客与赞助商页面留给第 8 步后续变更。

## 关键选择

沿用现有 Phaser 投影，以程序化几何构成可随游戏状态变化的设施。游戏厅先出现底座和发光玻璃罩，再按展示游戏的份数添置机柜。首批没有外部 3D 模型文件和镜头旋转。

## 验收条件

- [x] 地图和面板显示服务端的地块、价格、设施、展示份数及建设工作。
- [x] 手动买地、建游戏厅、制作游戏并放入后，设施和面板同步更新。
- [x] 内容数量只属于当前 `view_as` 居民，公开居民视图不泄露物品栏。
- [x] 没有新快照时，工作倒计时和展示内容到期仍在页面及时更新。
- [x] 方块居民走路摆臂小，四种设施共享底座与发光玻璃边。
