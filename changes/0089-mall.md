# 0089：商场

状态：已完成（客户端 `npm run verify`、服务端 `make verify` 通过；无头 Chrome 截图核对了模型；独立审查没有确认的缺陷，已补审查指出的许可与占地测试）。

## 目标与依据

用户（2026-11-09）：新设施“基础设施商场”，建好就能直接吸引游客、不需要内容；建造花费略低于游戏厅等大型设施，收入远低于游戏厅，对游客的吸引力有限；占地 10 × 20；建模用 `demos/voxel_mall_exterior_palettes.html` 的“雾蓝珊瑚”配色加夜景；单独写设计文档。

可观察的变化：居民和玩家能在 1 × 2 块自己的空地上建商场；建好后访客会去，每人付 2 金币，付款日按份额分给持有人；地图上画出夜景的六层商场。

## 范围

- 服务端：设施种类 `mall`、占地按种类算（1 × 2）、建造工作 `build_mall`（工作量 200）、许可与委托支持 `mall`、入场费 2、访客候选与停留、AI 的 `build_venue` 与观察 `mall_room`、`compute.mall`、系统提示；协议 29。
- 页面：协议与占地算法同步，设施面板“建商场”，选中框与命中体积按长方形，`render/mallModel.ts` 与 `plotShape.ts` 支持窄长模型。
- 文档：新设计文档 [商场](../docs/design/mall.md)，更新场所设计的相关链接、设计索引、代码地图、状态。
- 不做：商场里的内容与商铺、横放与旋转、数值的快进模拟。

设计文档：新建 `docs/design/mall.md`。

## 关键选择

见设计文档“争议讨论与决定”。要点：商场是第三种场馆（沿用建造、占地与分账）；数值（工作量 200、入场费 2、吸引力 0.4 份）由 Claude 按“略低、远低、有限”定，尚未模拟；受光颜色预压暗来还原 demo 的夜景。
