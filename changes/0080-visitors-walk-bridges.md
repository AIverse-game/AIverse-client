# 0080：访客只走桥和传送门，岛间距再拉大一点

状态：已完成（两个仓库的自动检查通过；服务端的步行规则有单元测试，页面只改了岛的缩进；未在浏览器里看访客，因为页面不画访客）。

## 目标与依据

用户（2026-11-08）在岛换成光桥之后问是不是也要改寻路，并定了：现在就做；访客严格只能走桥和传送门；Agent 居民不需要加浮起的视觉效果（居民仍可浮空直走）；岛和岛之间的距离可以稍微拉大一点点。

## 范围

- 服务端：新增 `economy/islands.py`：按街区算出每座岛（每边缩进 `ISLAND_INSET` = 2，与页面一致）和岛间的桥（相邻两岛相对的两侧的中点，先东后南，与页面 `islandLinks` 同序）；`walk_from(map, 起点)` 给出到任一点的最短步行距离和折线（岛内直走、跨岛过桥）。`portals.Router` 改用它：直走一律按岛和桥算，走传送门线路时前后两段步行也按岛和桥算。`Visitor.via`（两个传送门）改为 `legs`（走过的各段直线，传送的那一跳不在其中），位置和展示的计算沿着这些段。游荡的目标限制在自己的岛上。
- 每个街区只有一块地的地图（`block_cells` 为 1）没有岛，行为不变。
- 页面：岛的缩进从 1.5 改为 2，缝隙从 3 变 4 个单位，桥随之变长到约 3.4；大厅岛 26 个地图单位宽。
- 居民（含 AI）的行走不变，直线浮空。
- 不做：页面画访客；居民沿桥走；桥的容量或收费。

设计文档：修改 [脚本访客](../docs/design/visitors.md)、[交通：传送](../docs/design/portals.md)、[出生大厅与 NPC](../docs/design/lobby.md)。

## 关键选择

- 桥的位置在服务端和页面各算一份，和街区坐标的做法一样。服务端测试和页面测试各断言同样的头两座桥（岛 0 到岛 1：(28, 15)–(32, 15)，岛 0 到下方岛：(15, 28)–(15, 32)），对照起来发现不一致。
- 步行图很小（5 × 5 座岛，80 个桥端），每个起点只算一次到各桥端的最短距离并缓存，所以选目的地时每个候选只要比较一座岛的至多 4 个桥端。
- 缝隙 4 的代价：设施模型铺满地块，最外圈的设施探出岛沿更多（工作空间和游戏厅约 1.7 个单位，广告位和传送门约 0.8）。要根治需要让设施收进岛里，留给后续。
- 访客绕桥走，路变长，走路时间进了选目的地的效用，也影响展示的计数。在默认世界里放 74 块带广告位和传送门的地，模拟 600 游戏秒，展示总数从约 7200 降到约 6500（−9%），CPU 时间从 2.3 秒到 3.3 秒。赞助商出价和预算没有跟着调。

## 验收条件

- [x] 同一座岛上的两点之间直走；相邻两岛之间的步行经过桥口，距离等于到桥口、过桥、再到目标；对角的岛要过两座桥。
- [x] 没有岛的地图所有步行仍是直线。
- [x] 访客去另一座岛的广告位时，路线的各段是岛内直线加桥，用时按这条折线算。
- [x] 游荡的目标不离开所在的岛。
- [x] 访客走传送门线路的既有行为（用时、跳过的一段不算展示）不变。

## 验证证据

- 服务端 `make verify`（ruff、格式、mypy、pytest）通过，1204 个测试，其中新增 `tests/unit/economy/test_islands.py`（含边长 160 的非整除地图的桥位）和 `test_visitors.py` 里过桥、传送门加桥的两条；原来断言 `via` 的三处改为断言 `legs`。
- 独立审查（子 Agent，只读）：另写脚本把客户端 `islandLinks` 和街区算法照搬成 Python，与服务端的桥位在 6 种地图（含最后一列较窄的）上逐一比对一致；用暴力最短路对照 `walk_from` 的距离和折线，在三种地图上各 40 对随机起终点全部相等；没有确认的问题。按它指出的测试缺口补了非整除地图的桥位测试（两个仓库各一条）和传送门加桥的组合测试，并改了一处滞后的文档措辞。
- 客户端 `npm run verify`（164 个测试）与 `python3 scripts/check_repo.py` 通过。
- 脚本模拟（见上）：600 游戏秒的 CPU 时间和展示总数前后对比。
- 未验证：页面里实际的缝隙观感（缩进 2 只改了常量，没有再截图）；真实游戏里访客的流量分布。

## 交接

- 审查留下的疑点：没有大厅的偶数街区地图（如 120 / 3）上，访客的入口恰在两座岛的缝里；默认地图不受影响。展示计数跨多段折线、缝隙里起步的步行、游荡贴岛沿的行为没有专门的测试。

- 页面开始画访客时，位置就是 `visitor_position`，会自然沿桥走。
- 赞助商出价、预算和入场费都没有按新的路程重调。
- 桥的位置有两份实现；再改桥的摆法要两边一起改。
