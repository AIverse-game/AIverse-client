# 0088：游戏厅里按游戏数摆机台

状态：已完成（`npm run verify` 通过，已在无头 Chrome 里截图核对，独立审查没有确认的运行缺陷）。

## 目标与依据

用户（2026-11-09）：把 `demos/arcade_hall_machines_mecha.html` 里的五台游戏厅设施（街机、抓娃娃机、全息台、赛车模拟器、跳舞机）移植到前端；游戏厅每多一份内容（游戏）就在厅里放一台，5 份放满为止；如果可以，把这部分渲染独立出来，方便以后移植和调整。

可观察的变化：游戏厅里不再是通用柜体，而是 demo 里的机台，带动画；1 份游戏摆 1 台，5 份摆满 5 台。

## 范围

- 新增 `render/arcadeMachineModels.ts`：五台机台的建模与动画，只依赖 `sceneKit.ts`，不知道游戏厅和协议。对外是机台表 `MACHINES`（顺序、名字、demo 里的位置与朝向）、`machinesFor(contents)`（几份游戏摆哪几台）、`createMachine(spec, theme)`（建一台，返回 `ModelHandle`）和发光主题 `MACHINE_THEMES`（琥珀橙、电光蓝）。
- 改 `render/arcadeModel.ts`：去掉通用柜体，按 `machinesFor` 摆机台（放大 1.3 倍，位置按 demo 的坐标缩放），逐帧更新机台动画，释放时一并释放。
- 文档：[场所设计](../docs/design/venues.md)、代码地图、状态与索引。
- 不做：机台名字标签、按游戏本身选机台、页面上切换发光色（主题已做好，没有接入）。

## 关键选择

- 机台和厅分成两个文件：以后换位置、缩放、发光色只改厅里的几个常量；机台模型也能被别处直接取用。
- 机台靠 `ModelBuilder` 按材质合并静态方块，只有会动的部分（摇杆、爪子、屏幕、立方体、踏板）单独成对象，避免一座厅几百次绘制。
- 抓娃娃机的奖品用固定种子，每次重建外观相同；抓取目标用随机数。
- 摆放数量以 `contents` 为准，截到 5。游戏份数变化时厅整座重建（沿用 `FacilityLayer` 的做法），机台动画会从头开始。
