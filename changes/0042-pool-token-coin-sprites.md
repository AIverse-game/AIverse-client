# 0042：矿池、token 与金币贴图

状态：已完成。

## 目标与依据

用户提供四张透明 PNG：矿池地面贴图、矿池上方悬浮的标记、token 图标和金币图标，并要求悬浮标记旋转并上下微微浮动。地图上的矿池原本是半透明色块加一颗多边形水晶，页面上的 token 与金币只有文字。

## 范围

只改客户端资源、Phaser 矿池渲染和页面小图标；协议、服务端和玩法不变。

- 地图：矿池以贴图铺在地面，贴图贴合服务端矿池半径的投影椭圆；水晶改为悬浮标记，绕竖轴旋转并上下浮动，相邻矿池错开相位，储量用尽的矿池整体变淡。
- 页面：居民列表的 token、矿池剩余储量前加 token 图标，金币排名前加金币图标；旁边仍有文字，图标不带替代文本。

设计文档：无，不改变功能设计。

## 关键选择

- “旋转”按悬浮标记的惯例理解为绕竖轴转，贴图左右对称，所以只缩放宽度（取余弦的绝对值，最窄 0.1，避免侧面时消失）；若要平面内转动，只需改 `render/poolMarkerMotion.ts`。
- 动画用 `performance.now()` 在 Phaser `update` 中驱动，与行走一致，不依赖 Phaser 的时钟；运动公式是纯函数 `markerPose`，有单元测试。
- 原图完整保存在 `assets/pools/`、`assets/tokens/`，运行时使用裁到可见像素（alpha 大于 8）后缩小的版本：矿池 256 px 宽、标记 128 px 高、两个图标 64 px，做法同市场与芯片贴图，避免把 1254 px 图缩到几十像素产生锯齿。

## 验收条件

- [x] 空矿池整体变淡；矿池数量或储量变化重绘后动画继续。
- [x] 居民列表、矿池列表和金币排名显示对应图标。
- [x] 类型检查、lint、测试、构建与仓库检查通过。

- `npm run verify`：类型检查、ESLint、测试（含新增 `markerPose` 单元测试）和生产构建通过。
- 浏览器：在独立端口 8765 的测试服务端加预览页上，用无头 Chrome 间隔截图：六个矿池的标记宽度不同并随时间变化，贴图贴合地面，居民、矿池与排名的图标显示正常；测试进程已关闭，没有动用 8000 端口上原有的服务端。浮动高度只能在静态截图中对比，未录动画。

## 交接
