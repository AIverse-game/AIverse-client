# 0032：AI 行动时间线与经营方针

状态：已完成。

## 目标与依据

用户同意优先让玩家看懂 AI，并要求完成第一项：页面显示计划、实际动作、结果和资源变化，允许填写经营方针。

## 范围

- 服务端保存每名居民最近 30 个完成的决策轮，随所选居民的快照发送；重连可读取，停止或更换 AI 不清除。
- 地图下显示计划摘要、动作时间、参数、成败、资源变化和轮间变化，区分开始行走/采矿与完成。
- 页面输入可选的经营方针（最多 1000 字），按居民保存并传入模型提示；重新交给 AI 后生效。
- 修改既有 [AI 居民设计](../docs/design/ai-residents.md)，两端协议版本升级为 14。
- 真实模型多局对照需玩家的模型配置，本次使用本地模拟接口验证联动，不使用玩家密钥或产生外部调用费用。

## 关键选择

- 只传页面需要的有界投影，不发送完整观察、隐藏推理、密钥或异常原文。摘要是模型最终回复的短计划，不视为事实依据。
- 金币采用与排名相同的总额，含托管；动作净变化与轮间净变化分别显示，不能仅凭相关性认定收益原因。
- 沿用 `view_as` 可见范围，快照带居民 id，切换时不展示旧居民的记录。

## 验收条件

- [x] 可输入、保存经营方针，切换居民或刷新后恢复，提交后模型实际收到。
- [x] 完成的轮次显示摘要、成功或拒绝的动作和真实资源净变化；无动作和调用异常也有记录。
- [x] 时间线只发送所选居民，切换、重连、停止 AI 后行为正确，保留条数有界。
- [x] 两端自动检查与浏览器联动验证通过，完成独立审查。
