# 0039：收购价历史记录与折线图

状态：已完成。

## 目标与依据

用户要求（2026-10-31）：记录收购价的历史，并在页面上画折线图；没有人卖出、价格自然回升时也要定期记录。

收购价是时间的纯函数，服务端没有定时器，无人卖出时不会产生任何事件，所以只在卖出时记录会漏掉整段回升。

## 范围

服务端：`Market.history` 保存价格点（`PricePoint`：游戏时间、单价）。卖出时记下卖出前和卖出后的价格（同一时刻两个点，折线上是一个台阶）；其余时间由游戏时钟每隔 `MARKET_SAMPLE_INTERVAL` = 5 秒记一次，采样时刻进入 `next_due`，由 `settle_due` 补记，所以延迟的 tick 也会把漏掉的点补齐。最多保留 600 点。协议 17：`market.priceHistory`。

客户端：协议 schema 与版本 17；`ui/priceChart.ts` 把价格点排成折线坐标（纯函数）；`ui/PriceChartPanel.tsx` 用 SVG 画图，放在操作面板之后，不引入图表库。

设计文档：修改 [token 收购点](../docs/design/energy-market.md)。

## 关键选择

- 记录放在服务端世界里，页面连上时就能看到全局历史，刷新或晚加入的页面也一样；页面本地不存。
- 记价格点而不是记压力：页面不用再推算，也不依赖定价公式。
- 5 秒一点：一局 20 分钟约 240 个采样点；每个不同时刻的卖出占 2 个点，约 180 次以上就会超过 600 的上限，此时最旧的点被丢弃，折线开头缩短（审查中实测确认）。折线在 5 秒内是直线，足以看出趋势。
- 每次状态都带完整历史（最多 600 点，约 20 KB）：简单，暂不做增量；若状态变得太大再改。
- 手工构造、历史为空的收购点不记录（采样与卖出都不记）；默认地图开局就有一个 (0, 基准价) 的点。

## 验收条件

- [x] 无人卖出时，历史每 5 秒增加一个点，价格逐点上升。
- [x] 卖出时记下前后两个价格，同一时刻再卖只更新后一个。
- [x] 历史超过 600 点时丢弃最旧的。
- [x] 协议校验接受价格历史，拒绝缺失、负时间、非正价格。
- [x] 页面在价格历史不足以画线时给出提示，足够后画出折线、基准价虚线和坐标刻度。

## 交接

- 图表只在收到状态时更新（每 5 秒一次采样广播），不在两点之间用本地公式补到“现在”。
- 一局结束后图表停在最后一个点。游戏结束后 `next_due` 仍会返回下一个采样时刻（时钟在结束后已停，没有调用方受影响；若以后有人在结束的世界上调用 `settle_due`，会继续追加采样点）。
- 状态消息变大，后续若有性能问题考虑增量下发或降采样。
