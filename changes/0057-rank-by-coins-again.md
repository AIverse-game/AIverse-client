# 0057：排名回到只算金币

状态：已完成。

## 目标与依据

用户 2026-11-04 决定：局末不再给手里的东西估值，能量和晶核都不计，排名回到只算金币；在系统提示里鼓励角色在局中适时卖出。

依据是 0054 之后的第一局真实模型对局（服务端 `logs/`，2026-11-04 14:56 开局）。按收购点单价给能量估值，让囤积比卖出更划算：

- 松木带着 4,741 能量在收购点等了 8 轮不卖，理由是“能量按收购价计分”，得分一度 190,704。最后一次卖光，只拿到 25,447 金币（均价约 5.4），得分跌到 35,207。
- 这次抛售压低了收购价。小麦手里 2,043 能量的估值跟着缩水，得分从 90,930 跌到 18,923，阿青手里的 477 能量也一样被砸。
- 估值远高于实际能卖到的钱。而且结束时的收购价谁都能砸低，排名随之摇摆。

可观察的变化：

- 排名按金币总额（含报价、合约、汲能塔和买单中预留的金币），手里剩下的能量、晶砂、晶核都不计。
- 协议 21：居民不再有 `itemValue`、`score`。页面排名改回显示金币，说明里写明能量和晶核不计、要卖掉才算。
- AI 观察去掉 `item_value`、`score`。系统提示说明只有金币计分、剩下的东西结束时一文不值，并鼓励局中分几次、趁价格好时把能量拿到收购点卖掉，不要攒到最后一次大卖。
- 临近结束的提醒：留出时间回收购点卖能量，价格好时就卖，不要拖到最后一刻。
- 经济报告每人不再有 `item_value`、`score`，控制台不再打印得分一行；基尼系数回到“排名口径”。

## 关键选择

- **能量和晶核都不计**：用户选了两者都取消。收购点不收晶核，只能卖给其他居民，按进口价折算也等于假设了一个不存在的买家。
- **往前改、不回退版本号**：协议升到 21，不回到 19；0054 的变更说明作为历史保留，只在状态里注明已撤销。
- **提示词只鼓励、不强制**：服务端不在结束时代卖。提示里讲清楚两件事：大额抛售会压价，剩下的东西会作废。
