# 0097：商场加高、游戏厅罩子降低、人走在设施地板上

状态：已完成（`npm run verify` 通过；无头 Chrome 预览页核对了外观与人物站位；真实对局里没有看过）。

## 目标与依据

用户（2026-11-10）：把商场的建模做高一点，高于游戏厅现在的高度；把游戏厅的罩子降低一点；人物在有高度的地方行走时仍走在地面上，在游戏厅里只有头从地板上露出来，要解决。

可观察的变化：

- 商场从 6 层加到 10 层（模型 46 → 70 个单位高，约 11.1 → 16.7 个地图单位），高过游戏厅降低前的约 14.4。
- 游戏厅罩子从 39 降到 30 个模型单位（约 14.4 → 11.6 个地图单位），机台仍在罩内。
- 居民和访客走进有底座的设施（游戏厅、工作空间、商场、广告位、传送门、小花园）时站在它的地板上，不再埋在底座里。

## 范围

- 页面渲染：`arcadeModel.ts`、`mallModel.ts`（层数、`MALL_TOP`、转角灯箱按层数加长）；`plotShape.ts` 新增 `floorHeightAt`；`FacilityLayer.ts`、`garden/GardenLayer.ts` 的 `floorHeight`；`MapRenderer.ts` 把出生台与设施地板取较高者交给 `ResidentLayer`、`VisitorLayer`；`VisitorLayer.ts` 让访客的高度缓缓升降（居民本来就是）。
- 不做：设施里的台阶、上下楼、商场内部；墙体碰撞（居民和访客仍可直线穿过设施）；点选设施内的居民（设施的命中体积盖住整块占地，站在里面的居民现在看得见，但点到的是地块）；Shift 点击走路的目标按地面 y = 0 算，点在高处的人或地板上会有偏移。

设计文档：修改 `docs/design/mall.md`、`docs/design/venues.md`。

## 关键选择

- 用设施自己的 `plotShape`（底座范围与 `floor`）算地板高度，不另存一份几何；游戏厅、商场的底座与模型范围一致。
- 十层是 Claude 定的，只要求高于游戏厅当时的高度（约 14.4）；十层约 16.7，降低罩子后也高出约 5。
- 不处理塔楼内部：商场的楼层是实心的，走进商场的访客站在广场地面的高度，不算问题。
