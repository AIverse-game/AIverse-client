# 0045：放大地图显示并修正矿机落点

状态：已完成。

## 目标与依据

用户要求把整张地图相对角色放大，同时保持角色贴图大小不变；矿机当前画在矿池旁边，要求落在矿池上。

## 范围

只调整客户端画布与矿机的显示坐标，不改服务端 150 × 150 地图、矿池半径、角色移动或矿机规则。矿机设计说明同步更新。

## 关键选择

- 画布宽度仍为 1200 像素，高度从 800 增至 1000 像素，页面容器同步改为 6:5。投影不再受高度限制，地图横向占用从约 932 增至 1104 画布像素，约放大 18%；居民贴图仍按原有 `FIGURE_HEIGHT` 和 `RESIDENT_SCALE` 绘制。
- 原矿机位置在矿池中心右侧另加 70 像素，与矿池尺寸无关。现在以矿池半径的 55% 为落点距离，因此底脚始终在矿池的圆形范围内。同池多台矿机显示一个带台数的标记，避免贴图重叠；单台时仍显示四个插槽灯，多个矿机的具体状态在侧栏查看。点击机身仍以矿池中心作为行走目标。

## 验收条件

- [x] 地图的屏幕占用变大，居民贴图尺寸常量不变。
- [x] 有矿机的矿池上可见矿机，矿机底脚落点在矿池范围内；同池多台矿机显示数量而不叠加贴图。
- [x] 地图与点击坐标继续共用同一投影。

- `npm run verify`：类型检查、ESLint、180 项测试、生产构建通过；`python3 scripts/check_repo.py` 与 `git diff --check` 通过。
