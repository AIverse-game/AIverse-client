# 0046：三倍可滚动地图

状态：已完成。

## 目标与依据

0045 的地图仅放大约 18%，用户要求地图相对角色至少再放大几倍，角色贴图大小保持不变。

## 范围

客户端地图画布、页面视窗与滚动导航；服务端地图坐标、矿池与角色贴图尺寸不变。地图显示设计同步更新。

## 关键选择

- 地图画布由 1200 × 1000 扩至 3600 × 3000 逻辑像素，边距和顶部留白同乘 3；页面上的地图容器宽度也由一个视窗宽扩至三个视窗宽。地面在屏幕上的宽度因此是 0045 的 3 倍，而角色和其他立式贴图的画布像素尺寸不变。
- 页面地图视窗固定在可视高度内，初始滚动位置居中。短视窗下地图宽度上限也同步扩大 3 倍，以保持角色贴图的屏幕尺寸。鼠标滚轮纵向滚动，横向滚轮或 Shift 加滚轮横向滚动；滚轮的行与页单位先换算为像素，滚动条也可访问整张地图。滚动时刷新 Phaser 的画布边界缓存，使点击反算立即使用新位置。

## 验收条件

- [x] 地图相对角色在页面上显示为 0045 的 3 倍，角色贴图绘制尺寸未改。
- [x] 默认视窗居中，地图边缘可经纵向和横向滚动到达。
- [x] 坐标投影与反算、矿机落点仍通过现有检查。

## 验证证据

- `npm run verify`：类型检查、ESLint、185 项测试、生产构建通过；`python3 scripts/check_repo.py`、`git diff --check` 通过。
- Chrome 本地页面：画布为 3600 × 3000，CSS 显示为 3030 × 2525，视窗为 1010 × 735，初始滚动位置约 (1010, 895)；滚轮可访问地图边角。1400 × 600 短视窗下，地图宽 2070 px，是旧高度上限 690 px 的 3 倍。居民与矿机贴图保持原来的屏幕尺寸。
- 独立审查发现短视窗尺寸、滚轮单位和滚动后 Phaser 点击坐标缓存三个问题，均已修复并经只读复核。浏览器中的对局已结束，无法通过移动指令实测滚动后点击的目标坐标；`updateBounds()` 调用路径及 Phaser 坐标反算由代码复核确认。
