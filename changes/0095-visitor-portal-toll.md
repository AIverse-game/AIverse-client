# 0095：访客走传送门线路网付小额过路费

状态：已完成（服务端 `ruff`、`mypy`、`pytest` 通过；协议、页面不变）。

## 目标与依据

用户（2026-11-10）：“让访客付过路费，但访客不看金币，别太贵。”此前访客走线路免费（变更 0072），传送门自己不赚钱，只有居民传送才有过路费。

可观察的变化：访客选了线路网里的路，走一趟，进门的那座传送门所在地块和出门的那座各得一半过路费，在付款日随入场费按份额分给持有人；访客选目的地时不计这笔钱，所以不改变访客去哪。

## 范围

- 服务端：`economy/admissions.py` 加 `VISITOR_TOLL = 1` 和 `charge`；`economy/portals.py` 的 `Route` 带 `portals`（进门、出门两座传送门的地块号，同一座则为空），`Router` 填它；`economy/visitors.py` 在访客出发走线路网时记账；AI 的系统提示与 `build_portal`、`link_portals` 工具说明改成访客付小额过路费；文档与测试。
- 不做：用主人定的过路费（0～1000）；访客按段付费；让线路网的形状影响访客；页面显示。

设计文档：修改 `docs/design/portals.md`、`docs/design/visitors.md`。

## 关键选择

- **由系统定价、钱来自镇外，不用主人写的过路费。**访客不看金币，主人把它定到 1000 就等于从镇外印钱；沿用入场费的做法，访客不需要钱包（用户 2026-11-07 的纠正仍然有效）。
- **每趟每人 1 金币**，和最便宜的入场费（花园，1 金币）一样，乘访客代表的人数。“别太贵”由 Claude 取最小的整数，快进模拟里它约占入场费的 1.3%。
- **一半给进门、一半给出门的地块**，和居民传送的分法一致；记在入场费的账上（`AdmissionBook.unpaid`，不计入 `admitted`），在付款日整枚付出，渠道 `visitors`。
- **出发时记账**，不等走完：路线在出发时定下，访客不会半路改，也不必在访客身上多存状态。
- **不改选路**：`Router` 的距离不含过路费。因为不计成本，线路网在访客眼里仍是同一网里任意两座门之间不花时间，网的形状不影响访客；要让形状起作用需另加每段成本或段数上限，留待用户决定。

## 验收条件

- [x] 访客经线路网走时，进门和出门两座传送门的地块各记 `权重 × 1 ÷ 2`，不记入 `admitted`。
- [x] 主人定的过路费（0 与 1000）不改变访客付的钱和走的路。
- [x] 只步行的访客不付过路费。
- [x] 回入口的路经线路网时也付。
- [x] 记在传送门地块上的过路费在付款日按份额付给持有人，零头留到下次。
- [x] 关掉记账后上述新增的访客用例失败，开着时通过。
