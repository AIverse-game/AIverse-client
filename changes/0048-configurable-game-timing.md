# 0048：游戏时长与结束公告时间独立配置

状态：已完成。

## 目标与依据

上一局模型请求多次耗尽 180 秒等待上限，20 分钟局中多名居民错过了出售窗口。用户同意用 40 分钟对照试玩，并要求游戏时长与两次公告提前量都可配置；游戏配置按开发规范放在 `game/config/`，与 `agents/config/` 中的大模型配置分开。

## 范围与选择

- 服务端新增 `game/config/game.example.yml` 和独立的 `game.yml` 加载、校验；缺省仍为 1200/180/60 秒。
- `--game-config` 指定另一份游戏配置；已有的 `--duration` 继续覆盖其中的对局时长。
- 公告文案、模型系统提示与临近结束的回复上限触发时刻跟随提前量变化。
- 本机被忽略的 `game.yml` 设为 2400/300/120 秒，供下一局对照试玩；不提交本地配置。

## 验收条件

- [x] 读取三项时间并拒绝无效值或错误的公告顺序。
- [x] 在配置时刻各公告一次；模型使用相同的提前量。
- [x] 旧配置及未提供游戏配置时保持原默认行为。
