# 0043：居民贴图与浮动

状态：已完成。

## 目标与依据

用户（2026-11-01）提供一张居民贴图（会漂浮的小精灵），并要求移动时也有浮动感。地图上的居民原本是用图形画的站立小人。

## 范围

只改客户端资源和 Phaser 居民渲染；协议、服务端和玩法不变。

- 居民改用贴图，悬在地面上方一点；静止时慢速小幅上下浮动，移动（服务端报告的行走，或点击移动的补间）时浮动更快、幅度更大，两种速度之间在约 0.3 秒内渐变，不跳变。
- 贴图对所有居民相同，居民各自的颜色改画成脚下的一个彩色圆盘，叠在原有的影子上；影子随升降缩放（升高变小）。名字标签、选中圆环、点击选中仍沿用原来的做法，标签与点击区域按新的高度调整。

设计文档：无，不改变功能设计。

## 关键选择

- 贴图只有一种配色，直接染色会让橙色小精灵的颜色混乱，所以用地上的圆盘区分居民；侧栏的色块和名字不变。若想让居民本身也有颜色，需要每个颜色一张图或分层贴图。
- 浮动的状态（角度和快慢程度）按每帧时间累加而不是直接用时钟算，快慢切换时角度连续，不会抖动一下；一次最多按 100 毫秒累加，页面切到后台再回来不会突然跳。每个居民的起始角度随机，不会一起升降。公式是纯函数 `stepFloat`、`floatPose`，有单元测试。
- 原图完整保存在 `assets/residents/resident.png`，运行时用裁到可见像素（alpha 大于 8）后缩到 128 px 高的 `resident-sprite.png`。

- [x] 静止时缓慢浮动，移动时更快更大，并在停下后渐变回去。
- [x] 类型检查、lint、测试、构建与仓库检查通过。
