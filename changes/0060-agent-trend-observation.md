# 0060：给 AI 居民提供有界走势观察

状态：已完成。

## 目标与依据

2026-11-05 用户希望居民根据过去的状态预测下一步走势，而非只看到当前快照。先前真实模型对局约消耗 462 万 API Token；把整局快照逐轮重发会继续增加费用。本次让模型看到足以判断市场和资源变化的短时间序列，同时保持每轮输入有界。

## 范围

- 服务端 Agent 观察增加收购点最近 5 分钟的价格与匿名卖出量、交易所最近 8 笔匿名成交，以及居民确实见过的能量泉储量样本。
- 提示模型根据历史做短期预测，并使用已有短期笔记记录重要预测与之后的检验。
- 不改游戏结算、页面协议或客户端界面；预测与结果的专门页面展示留待后续设计。

设计文档：[AI 居民](../docs/design/ai-residents.md)。

## 关键选择

- 每轮仍是独立模型对话，不假装模型能保留未重发的上下文；用最长 5 分钟的滚动样本代替全局状态回放。
- 能量泉历史只记录居民实际见到的储量，走远以后不泄露真值；交易记录不暴露买卖双方。
- 先沿用已有 `remember` 工具保存预测，不新增面向玩家的协议字段。

## 验收条件

- [x] 模型观察含有有界的收购价与交易成交历史，可从中看出涨跌及成交量。
- [x] 能量泉离开视野后，历史和最后已知储量都不会从世界真值更新。
- [x] 每轮原有资源、报价、排名等观察仍可用，脚本机器人和页面协议不受影响。
- [x] 服务端验证与独立审查完成。

## 验证证据

- 服务端 `make verify`：ruff、格式检查、mypy 与 1158 个测试通过。
- 客户端 `python3 scripts/check_repo.py`：仓库文档与链接检查通过；未修改客户端运行代码。
- 独立审查发现价格历史上限会让仍有销量的旧时间桶消失；现保留该桶销量，缺失价格为 `null`，并增加回归测试。过时的“未真实试玩”文字已删除；复核通过。

## 交接

专门的预测结构、到期自动评估、玩家可见的“预测—行动—结果”复盘尚未实现。下一步应先用相同种子对照实际模型对局，测量输入 Token、预测是否被使用，以及交易收益和行动失败率。
