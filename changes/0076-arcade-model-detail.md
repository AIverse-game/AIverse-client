# 0076：细化游戏厅模型

状态：已完成。

## 目标与依据

用户指出首版游戏厅底座缺少细节、占地面积太小、玻璃外壳太矮。地图中的空游戏厅也应有接近参考图的建筑体量和可辨认的结构。

## 范围

调整前端 Phaser 2.5D 的游戏厅绘制和设施点击区域。游戏规则、协议、其他设施的外观和居民不变。设计补充在[虚拟设施](../docs/design/facilities.md)。

## 关键选择

游戏厅边长由地块的 76% 增至 95%，玻璃罩顶由 3.2 升至 6.2 地图单位。底座增设双色侧面灯带、接缝、地砖和室内灯带，四角设带灯的柱子，靠近观察者的一面设入口框。仍用程序化几何，后续内容份数继续决定机柜数量。

玻璃罩抬高后，沿用地面反投影会把罩顶误判为邻地；设施尺寸和屏幕凸包共用一份几何参数，点击罩体时直接选中所属地块。

## 验收条件

- [x] 空游戏厅占地接近整块地，玻璃罩高于室内设施。
- [x] 空场就能看清底座的分层、地砖、发光边和入口。
- [x] 其他设施的占地与高度不受影响。
- [x] 点击罩顶或玻璃侧面仍选中游戏厅地块，点其他地面仍按地面坐标选地。
- [x] Shift 点击仍按地面点击位置行走，不改成地块中心。
