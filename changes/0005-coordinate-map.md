# 0005：正方形坐标地图

状态：已完成。

## 目标与依据

用户要求：在服务端生成一张有限大小的正方形地图，带坐标系统；前端读取后正确渲染。实现前确认的决定见 [决策 0002](../docs/decisions/0002-python-server-and-coordinate-map.md)：使用 Python 后端；不要五个区域，也不要网格，居民等对象使用连续 `x, y` 坐标；固定布局；前端彻底切换到 Python 服务端；本次不做移动。

可观察的变化：启动 Python 服务端和网页后，页面显示一张带刻度和网格线的正方形地图，原点在左上角；四名居民画在服务端给出的坐标上，侧栏列出地图边长和每名居民的坐标。服务端不可达或消息不符合协议时，页面显示错误。

## 范围

- 新建 `aiverse-server`（与本仓库同级）：世界模型与坐标校验、固定布局、协议模型、WebSocket 接口、启动入口、测试。
- 本仓库：协议包改为地图与居民视图，并校验服务端消息；新增 WebSocket 连接；Phaser 场景按坐标绘制地图、刻度、居民和指针坐标；侧栏显示地图信息；Vite 代理 `/ws`。
- 删除五区域的规则引擎、宿主、规则 Agent、Worker 本地服务端，以及依赖它们的面板（我的居民、排行榜、行动记录）。
- GitHub Pages 部署工作流改为只做检查的 CI。

留给后续：居民移动及速度、回合时钟、地点与物品、生产与交易、房间、身份认证、断线重连、跨语言契约测试。

## 关键选择

见决策 0002。坐标约定：边长 `size`（当前 100），原点在左上角，x 向右、y 向下，取值闭区间 [0, size]，允许小数。刻度按 1/2/5 × 10ⁿ 的整齐步长，每轴约 10 格，地图大小变化时自动调整。

## 验收条件

- [x] 服务端生成固定布局的 100 × 100 地图和 4 名居民；构造越界、坐标为 NaN/无穷、边长非正或 id 重复的世界会被拒绝；边界上的坐标被接受。
- [x] 客户端发送 `hello` 后，服务端依次返回 `welcome` 和带地图的 `state`；非 JSON、二进制帧、未知类型、字段类型错误得到长度有限的 `bad_message`，版本不符得到 `protocol_mismatch`，之后连接仍可用。
- [x] 客户端拒绝越界坐标、非正边长、错误颜色、重复 id 等不合协议的消息，并在界面报错。
- [x] 坐标换算：原点映射到地图左上角，(size, size) 映射到右下角，x 只影响横向、y 只影响纵向；画布坐标可以换算回地图坐标。
- [x] 浏览器实测：居民画在对应刻度上，与侧栏坐标一致；服务端未启动时显示“无法连接”。
- [x] `npm run verify`、`python3 scripts/check_repo.py` 和服务端 `make verify` 通过。

## 验证证据

环境：macOS，Node 22.19.0，Python 3.12.10（uv 0.10.10），Chrome 无头模式。日期 2026-10-26。

- 服务端 `make verify`（在 `aiverse-server` 中）：ruff check、ruff format --check、mypy strict（8 个文件）均通过；审查修复后 pytest 38 个测试通过（有一条 Starlette 关于 httpx 的弃用警告）。
- 本仓库 `npm run verify` 退出码 0：两个工作区 tsc、`eslint .`、Vitest 4 个文件 36 个测试、`vite build`。
- 端到端：`uv run aiverse-server` 加 Vite 开发服务器，无头 Chrome 1400 × 1000 截图。阿青 (20, 25)、小麦 (72, 18)、松木 (35, 70)、白露 (82, 84) 均落在对应刻度交点附近，侧栏文本与服务端数据一致，服务端日志显示 WebSocket 连接被接受。首次截图发现画布被容器撑高、上方留白，给 `.map` 加 `overflow: hidden` 后复测正常。
- 520 px 宽截图：地图缩放后完整显示，侧栏在下方，无横向溢出。
- 停掉服务端后刷新：顶栏显示“无法连接”和“无法连接服务端（ws://127.0.0.1:5287/ws）”。
- 审查修复后复测：服务端改用 8011 端口，Vite 设 `AIVERSE_SERVER_PORT=8011`，截图渲染与之前一致；用 websockets 客户端向真实 uvicorn 发送 10 万层嵌套和 5000 位整数的帧，都得到 `bad_message`，之后 `hello` 正常，服务端日志无异常。
- 未执行：390 px 手机宽度（无头 Chrome 最小视口为 500 px）；鼠标悬停显示指针坐标只有换算函数的单元测试，没有在浏览器中实际操作；生产构建配合 `vite preview` 代理未实测（与开发服务器使用同一份代理配置）。
