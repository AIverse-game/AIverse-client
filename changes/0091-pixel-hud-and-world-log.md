# 0091：全屏像素风界面与世界日志

状态：已完成。

## 目标与依据

用户（2026-11-10）：世界不再放在框里而是占满屏幕，右侧仍是操作面板，整体科幻像素风，字体尽量像素风；增加同样风格的“世界日志”面板，输出每个人做的每一件事（广播、私聊、建筑、买地等），写成“A 对 B 说：内容”这样的自然语言，像终端一样新事件追加在最下面；变更写成设计文档。

可观察的变化：地图铺满窗口，顶栏、面板列和日志窗口浮在地图上；界面是直角霓虹面板与像素字体；顶栏的“世界日志”打开一个终端式窗口，逐行显示全镇发生的事。

## 范围

- 服务端：`World.world_log`（`core/world.py`），`game/world_log.py` 的 `perform_logged` 与 `record_finished_jobs`；`app.py`、`agents/tools.py` 改用 `perform_logged`，`clock.settle_due` 记录完成的工作；协议 31 的 `worldLog`；单元与 WebSocket 测试。
- 页面：协议 31；全屏布局、顶栏开关、面板列收起；`WorldLogPanel.tsx` 与 `worldLogText.ts`；重写 `styles.css`；两个字体依赖；`exchange.ts` 补两个商品名。
- 文档：新建[设计文档](../docs/design/game-screen.md)与[决策 0008](../docs/decisions/0008-pixel-fonts.md)，更新状态、代码地图、架构与服务端 README。
- 不做：时钟引起的收入、到期等记录，日志筛选与拖动，开关状态持久化。

设计文档：新建 `docs/design/game-screen.md`。

## 关键选择

见设计文档“争议讨论与决定”：服务端记结构化日志、页面拼句；私聊在世界日志里对所有页面可见；`perform_logged` 包一层避免循环导入；字体见决策 0008。

## 验收条件

- [x] 地图铺满窗口，面板浮在地图上；“操作面板”可收起整列面板，窄屏时面板贴底。
- [x] 界面使用像素字体（浏览器确认 Fusion Pixel 已加载），面板、按钮、输入框为直角霓虹风格。
- [x] “世界日志”打开后逐行显示说话（含别人的私聊）、行走、买地、开工、建成、报价与答复等，句子形如“甲 对 乙 说：……”，最新一行在最下面并自动跟随。
- [x] 不选任何居民的页面也能在日志里看到别人的私聊（WebSocket 测试）。
- [x] 被拒绝的原语不进日志；日志只保留最近 200 条，序号连续。

## 验证证据

- 服务端（`aiverse-server`）：`make verify` 通过，ruff、ruff format、mypy 无问题，pytest 1328 项通过（新增 `tests/unit/game/test_world_log.py` 12 项与一项 WebSocket 测试）。
- 页面：`npm run verify` 通过（类型检查、ESLint、Vitest 26 个文件 246 项、生产构建）；新增 `worldLogText.test.ts`，协议测试补世界日志的接受与拒绝。
- 浏览器：启动服务端（3 名脚本居民）和 Vite 开发服务器，用无头 Chrome（1600 × 900 与 420 × 860）截图核对全屏布局、日志窗口、收起面板和窄屏布局；日志中出现当众说、行走、买地、开工等行，控制台无报错，`document.fonts.check` 确认像素字体已加载。
- 独立审查（只读子 Agent）：无 P0～P2；P3 五项（传送记的是净支出而非过路费、合约答复不说明谁供货、节点时长像时刻、坐标读数可能被换行的顶栏挡住、设计文档一处定位描述不准）已修复，补了回归测试，并交回复核；复核确认五项解决，指出 900～1040px 宽时坐标读数仍会被顶栏盖住，实测 920px 重叠后改为该宽度下隐藏读数，再测 920、1000、1040 宽时读数隐藏，1041、1100 宽时显示且不重叠。两个待确认点（挂单立即成交与退出的连带影响只记一句、满 200 条后翻看时的滚动锚定）写进设计文档的“暂未实现的功能”。审查者用临时插件在全部服务端测试里对约 930 次原语执行生成日志并用 zod 校验，没有异常。
- 未在真实大模型对局和真机手机上看过；报价、合约等行只经单元测试，未在浏览器里出现过（脚本居民不发报价）。
