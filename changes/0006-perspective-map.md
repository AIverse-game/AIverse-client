# 0006：2.5D 透视地图

状态：已完成。

## 目标与依据

用户要求：把现在的俯视平面地图改为 2.5D 视角，参考《饥荒》（Don't Starve）。

可观察的变化：地图是一块从斜上方俯视、转了 45° 的方形地块，远处小、近处大，前侧露出土层厚度；居民是站立的小人，脚下有影子，近处的人遮住远处的人，移动时大小随远近变化。地图数据和坐标约定不变。

## 范围

- `render/layout.ts`：投影由“缩放加偏移”改为带偏航、俯仰的透视投影，可换算回地面坐标；画布改为横向。
- `render/MapScene.ts`：地块（顶面棋盘格、刻度线、土层侧面、草丛纹理）、坐标刻度、站立的居民与影子、按远近排序和缩放。
- 地图容器改为横向比例；侧栏说明改为新视角下的坐标方向。

留给后续：镜头旋转、缩放与平移，正式美术素材，地点和物品的渲染。协议与服务端不变。

## 关键选择

均为可逆的表现层选择，不改协议和坐标系：

- 镜头固定：偏航 45°，原点 (0, 0)（西北角）在最远的顶角，x 向右下、y 向左下；俯仰 40°；相机距地图中心 3.5 倍边长，远近大小比约 1.4。透视下直线仍是直线，所以地面四边形用投影后的四个角直接填充即可。
- 只画东、南两个近侧土层面；画布顶部额外留出 `HEADROOM`，站在原点的居民头和名字不被裁掉。
- 居民是面向镜头的竖直图形（billboard），脚底对准坐标；大小按该点的透视比例缩放，以地图中心为 1，与地图边长无关。
- 草丛纹理用固定种子生成，只是地面质感，不代表游戏对象。

## 验收条件

- [x] 原点投影到地块最上方的顶角，(size, 0) 在右、(0, size) 在左、(size, size) 在最下方；远处比例小于近处。
- [x] 整块地图（含土层）落在画布边距内；任何边长的地图得到同一画面。
- [x] 画布点可以换算回地面坐标；地图外和地平线以上返回空。
- [x] 浏览器实测：居民站在对应刻度上，与侧栏坐标一致；近处的居民压在远处的上面。
- [x] `npm run verify` 与 `python3 scripts/check_repo.py` 通过。
