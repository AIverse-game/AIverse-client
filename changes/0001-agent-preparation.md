# 0001：通用 AI 开发骨架

状态：已完成。日期：2026-10-25。

## 目标与范围

为 Codex 与 Claude Code 建立通用协作基础：统一规则、任务闭环、变更模板、决策模板、状态交接和仓库检查。不预设业务需求、应用架构或技术栈。

## 验收条件

- [x] 两个工具指向同一份开发规则。
- [x] 项目说明和模板不包含具体业务需求或产品设计。
- [x] 工作流程覆盖理解、实现、验证、审查与交接。
- [x] 提供变更说明、重要决策和当前状态的维护位置。
- [x] 提供无第三方依赖的仓库检查入口。
- [x] 只初始化本地 Git，不自动提交、推送或配置外部服务。
- [x] 运行仓库检查并记录实际结果。

## 验证证据

- `make check`：通过，检查 15 个必需文件、15 个文本文件及本地 Markdown 链接目标。
- `git diff --check`：通过；尚未跟踪文件的文本格式由仓库检查脚本直接扫描。
- 全仓库业务关键词及原分享链接引用扫描：无匹配；人工审阅入口、规则、流程与模板，均为通用内容。
- `git status --short`：准备文件尚未提交，无自动提交或推送。
- 尚无应用源码，因此没有应用测试、类型检查或构建结果。
