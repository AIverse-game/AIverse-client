# 0065：算力与节点

状态：已完成。

## 目标与依据

[虚拟设施](../docs/design/facilities.md)实施步骤的第 2 步，用户（2026-11-07）要求开始做，并要求计划里加入交通（传送）：地块偏远时辅以传送，流量更容易到达，自己的地块之间联动更好。传送本身放进设计文档，作为新的第 5 步，这一步不实现。

可观察的变化：居民有一份免费但慢的自带算力；可以雇一台节点做一件工作（按工作量付费），或订阅一台节点一段时间（按秒付费，闲着也收）；用工作在自己的空地块上建广告位，居民不用守着，可以边走边做。AI 居民多了 `buy_node`、`build_ad` 两个工具和观察里的 `compute` 部分。广告位建成后不产生收入（第 3 步才有），页面和协议不变。

## 范围

服务端（`aiverse-server`）：

- `core/compute.py`：订阅的节点 `Node`、进行中的工作 `Job`、`ComputeBook`（放在 `World.compute`）及一致性校验；`core/land.py`：设施 `Facility`（只有 `ad`），`Parcel.facility`；流水账渠道 `compute`。
- `economy/compute.py`：速率与价格常量、买节点 `buy_node`、开工 `start_build_ad`、完工 `finish_jobs`、节点到期 `expire_nodes`、取消 `cancel_compute`、下一个到点时刻。
- 原语 `BuyNode`、`BuildAd`（走路时也能用）；出局和对局结束时取消工作和节点；`clock.py` 按到点时刻完成工作、让节点到期。
- Agent：工具、观察、按状态选工具、被自己的工作完成唤醒、系统提示、脚本机器人。
- README。

文档：设计文档（交通：传送；第 2 步的取舍与数值；步骤顺延）、状态、代码地图。

留给后续：渲染式节点与内容（第 3 步）、传送（第 5 步）、协议与页面显示（第 6 步）。

## 关键选择

见设计文档“争议讨论与决定”中第 2 步的取舍：算力是速度、三种来源及首版数值、订阅的工作必须在到期前做完、工作在哪都能开、出局不退款、每块地一个设施、广告位暂无收入、只有生成式节点。传送的设计是 Claude 根据用户的想法写的提案，细节待实现时确认。

## 验收条件

- [x] 用自带算力开工，2 分钟后广告位出现，不花金币；期间居民可以走路、说话。
- [x] 雇节点开工，12 秒后出现，花 360 金币，流水账记 `compute`。
- [x] 订阅节点按秒收费，一次一件，几台节点并行；超出到期时刻的工作不能开始；节点到期后消失。
- [x] 不是自己的地块、已有设施、已有工作、来源在忙、节点不属于自己、金币不足、数量超限都被拒绝且世界不变。
- [x] 出局取消该居民的工作和节点，广告位不出现，不退款；对局结束全部取消。
- [x] AI 居民能看到价格与时间、自己的节点和工作，能买节点和开工，工作完成时被唤醒。

## 验证证据

2026-11-07，macOS：

- 服务端 `make verify`（ruff、ruff format --check、mypy strict、pytest）通过，869 项测试；新增的核心规则测试在 `tests/unit/economy/test_compute.py`，Agent 层在 `tests/unit/agents/test_compute_tools.py` 和 `tests/integration/agents/`。
- 冒烟局：`uv run aiverse-server --port 8767 --duration 140 --agent r1=scripted --agent r2=scripted` 跑完一局。r1 在开局买地并开工，第 120 秒自带算力做完被唤醒，局末写出经济报告。（r2 在第 23 秒开工，要到第 143 秒才做完，已过了 140 秒的局长，所以这一局没有看到它的广告位出现。）
- 独立审查（独立子 Agent）：未发现 P0/P1。处理了：系统提示里“走路时只能说话、撤单、退出”一句已过时（算力操作走路时也能做）；`build_ad` 的 `node_id` 类型检查；世界载入时补了几条不变式（同一地块一件工作、正在施工的地块不能已有设施、开工和买节点的时刻不晚于当前时刻）；提示里对 Agent 无意义的“退出游戏会丢节点”一句。保留未处理：节点数上限只在买节点时检查，不在载入时检查；工作做完时唤醒会在极少数情况下多唤醒一次。
- 未做：页面和协议未改，没有浏览器验证；没有用真实模型跑过新的工具选择。
