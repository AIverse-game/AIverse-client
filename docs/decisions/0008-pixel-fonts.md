# 0008：界面使用打包的像素字体

状态：采用。
日期：2026-11-10。

## 背景

用户（2026-11-10）要求界面改为科幻像素风，字体尽量用像素字体。界面文字几乎都是简体中文，像素字体必须覆盖常用简体字；页面在本机运行，可能离线，字体不应依赖外部网站。

## 候选方案

- **Google Fonts 等外链**：不增加依赖，但离线时退回系统字体；外链也把页面访问暴露给第三方。
- **@fontsource/dotgothic16**：日文像素字体，覆盖日文汉字，缺少“说”“买”“这”等简体字，混排时会掉回系统字体。
- **@fontsource/fusion-pixel-12px-proportional-sc**：Fusion Pixel 简体中文版，12px 比例宽度，含 3 万多个字形（检查过日志与面板常用字都在），OFL-1.1；包内只有一个约 600KB 的 woff2。
- **自己把 Zpix 等字体文件放进仓库**：许可与更新都要自己维护。

## 决定与依据

正文用 `@fontsource/fusion-pixel-12px-proportional-sc`，标志等拉丁字用 `@fontsource/silkscreen`（OFL-1.1，约 60KB）。两者都是 npm 依赖，在 `main.tsx` 里导入其 CSS，由 Vite 打进构建；不需要外网。

## 影响

- 新增两个运行时依赖，构建产物多约 600KB 字体，浏览器首次加载时下载一次；`font-display: swap`，加载前先用系统字体。
- 像素字体只在 12px 的整数倍时清晰，界面字号统一为 12px 和 24px。
- 字体包的版本更新按普通依赖处理；若以后需要更小的体积，可以按用到的字做子集。
