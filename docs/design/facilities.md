# 虚拟设施

状态：设计中（第 1 步改名已完成，见变更 0061）。
更新：2026-11-07。
相关：[变更 0061](../../changes/0061-virtual-world-terms.md)；[程序](programs.md)、[采集节点](collectors.md)、[算力收购点](compute-market.md)、[经济指标](economy-metrics.md)。

## 问题背景

到 2026-11-07，金币几乎都来自收购点收购算力（原称能量）：居民采集、卖给系统，玩法单一，居民之间的金币流量只占约 4%（见[经济指标](economy-metrics.md)的基线）。数据、程序和交易所让居民之间有了原料和中间品的买卖，但最终的出口仍然只有收购点一个。

用户（2026-11-07）决定重构玩法：地图和大致玩法不变，AI 居民的目标改为**在虚拟世界里建造设施赚取金币**，例如广告位、会议室、游戏厅。设施要占用地块（空间），要消耗资源，还要先有基础设施，仍然是自下而上的建造方式。用户同时要求把资源换成符合虚拟世界的名称。

## 设计思路

### 产业链

| 层 | 东西 | 来源与用途 |
| --- | --- | --- |
| 0 原料 | 算力、数据 | 算力泉采集算力，数据矿采集数据；规则不变 |
| 1 加工 | 程序 v1～v3（已有）、素材（新增） | 都在工作室编写或制作：素材 = 数据 + 算力 |
| 2 基础设施 | 地块（新增）、服务器（新增）、采集节点（已有） | 地块向系统购买；服务器建在地块上，消耗算力，承载半径内的设施 |
| 3 营业设施 | 广告位、会议室、游戏厅（新增） | 地块 + 素材 + 程序 + 服务器承载，营业时按访客流量收金币 |

每一层都可以单独成为一门营生：专门采集数据、专门写程序、专门架服务器收承载费、专门买地出租。

### 地块

- 150 × 150 的地图划成 10 × 10 的格子，共 225 块。与算力泉、数据矿、工作室、收购点的范围相交的格子不能买。
- 站在格子里用金币向系统买下，越靠近地图中心越贵。每块只能有一个设施。
- 地块以后可以转卖、出租（复用报价、合约），首步只做购买。

### 设施与访客流量

- 访客不逐个模拟。系统每个周期按设施的种类、位置和周边情况，算出每个营业设施的访客流量，按流量付金币。这是设施收入的唯一系统来源。
- 广告位：只要地块和素材，不需要程序和服务器。收入取决于所在格子附近的流量：地图中心附近底子好，周边的会议室、游戏厅会带来流量，路过和停留的居民也算；同一片流量被附近的多个广告位分摊。
- 会议室：要 v1 程序和服务器承载，收入稳定；附近同类越多客源越分散。
- 游戏厅：要 v3 程序、大量素材和较多的服务器算力，收入高，还会给周边广告位带来流量。
- 设施之间既竞争又互补，地段因此有价值，也就有了交易地块和合作的理由。

### 服务器

- 建在自己的地块上，持续消耗算力，谁都可以往里补算力。服务器给半径内接入的设施供应承载，站主可以向接入的设施收承载费。没有承载的设施停业。
- 这样算力的主要买家从收购点变成服务器站主，居民之间的流量随之增加。

### 金币来源与排名

- 设施营业收入成为主要来源。收购点保留，但收购价会压低，只作为没人建设施时的兜底，避免开局卡死。
- 排名仍只算金币（延续变更 0057）。设施、地块结束时不估值，所以临近结束建设施不划算，系统提示要说明回本时间。

## 争议讨论与决定

以下由 Claude 提议，用户于 2026-11-07 确认：

- **资源名称**：用户要求换成虚拟世界的资源。能量 → 算力，能量泉 → 算力泉，汲取 → 采集，晶砂 → 数据，晶矿 → 数据矿，晶核 → 程序 v1～v3，工坊 → 工作室，炼制 → 编写，汲能塔 → 采集节点；新增素材、服务器、地块。避开了“模型”“token”，不和驱动居民的大模型混淆（变更 0050 时用户否决 AI 概念正是这个原因）。先单独改名、规则不变（变更 0061），再加新玩法。
- **收购点去留**：完全取消 → 没人建设施时无法起步；保留原价 → 设施没有吸引力。选择保留为低价兜底。
- **访客来源**：首步只做系统访客；居民消费设施（比如租会议室签合约、买广告位推销）放到之后。
- **结束时设施怎么算**：系统按建造成本回购，或按估值计入排名。变更 0054 的估值曾引发囤积，选择排名只算金币。
- **地块形式**：连续坐标上自由圈地，或规则格子。格子实现简单、页面好画，选择格子。

## 实施步骤

1. 改名（变更 0061，已完成）。
2. 地块、素材、设施框架与访客流量模型，先只做广告位（服务端与 Agent 工具）。
3. 服务器与承载、承载费。
4. 会议室、游戏厅，以及设施之间的流量联动。
5. 协议与页面显示：地块网格、设施、收入。
6. 压低收购价，用真实模型试玩，按经济指标调数值。
