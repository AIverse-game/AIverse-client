# 当前项目状态

更新：2026-10-25。阶段：网页端底层框架已建立，可在浏览器中运行演示对局；经济玩法尚未实现。

## 已具备

- [AIverse 总体设计 v0.1](design/game-overview.md)：以玩家自带模型 API 驱动居民，进行生产和交易，最终按金币排名。规则和数值尚待原型验证。
- 网页端底层框架（[变更 0004](../changes/0004-web-foundation.md)）：TypeScript monorepo，分为协议、规则引擎、权威宿主、规则 Agent 与网页客户端，见 [应用架构](architecture.md) 与 [决策 0001](decisions/0001-web-stack-and-layering.md)。
  - 客户端主线程只渲染权威方推送的快照；权威方现以“本地服务端”形式运行在 Web Worker 中，经 JSON 消息通信。
  - 已实现的规则切片：五区域地图与逐跳移动、采集谷物/木材、制作面包、两种休息、等待、体力与背包上限、失败不产生部分扣减、60 回合后结束。
  - 宿主：固定回合节奏、决策截止、超时/异常/非法输出转为等待、迟到结果丢弃、按观察者裁剪私有信息。
  - 4 名调试用规则 Agent 演示座位；浏览器用户跟随其中一名（阿青）。
  - GitHub Pages 部署工作流，构建使用相对路径。
- Codex 与 Claude Code 共用开发规则、开发与审查 Skill、变更与决策模板。
- 本地 Git 仓库，分支为 `main`；文件尚未提交，未配置远程仓库。

## 当前可用命令

```sh
npm install
npm run dev                     # 本地运行
npm run verify                  # 类型检查、ESLint（含分层规则）、Vitest、生产构建
python3 scripts/check_repo.py   # 仓库骨架检查
make verify                     # 以上两项检查
```

验证证据见 [变更 0004](../changes/0004-web-foundation.md)。

## 待决定的设计问题

- **他人动作的可见粒度**：目前只对他人隐藏失败原因；采集、制作、休息事件公开，由于产量是常数，可以从事件流推算他人的背包和体力。设计第 6 节要求他人背包不公开，同时画面又需要展示居民在工作，需要决定其他 AI 和观战者能看到的事件粒度。
- **开局权限**：任何已连接的会话都能发出“开始对局”，包括观战者。本地只有一个会话，所以没有影响；接入多人房间时需要按房主或准备状态做判断。
